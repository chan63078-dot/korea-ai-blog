# SEO 구조 가이드

## 제목 (Title)
- 메인 키워드를 제목 앞부분에 배치
- 30자 이내
- 숫자·연도 포함 시 클릭률 상승: "2026년 OOO 완벽 정리"
- 의문형·정보형 혼용: "OOO란? / OOO 방법 총정리"

## 키워드 배치
- 도입부 첫 문단에 메인 키워드 1회 자연스럽게 삽입
- 본문 전체에서 메인 키워드 밀도: 1~2%
- 연관 키워드(LSI) 3~5개 자연스럽게 분산

## 메타 설명 (글 요약)
- 글 맨 앞 또는 도입부에 80~120자 요약문 작성
- 메인 키워드 포함 필수

## 내부 구조
- 소제목(H2/H3)에 키워드 또는 연관어 포함
- 이미지 alt 텍스트 제안 포함 (이미지 삽입 위치 표시)

## 마무리 키워드 밀도 확인
- 글 완성 후 메인 키워드 등장 횟수 = (총 글자수 / 100) × 1.5 기준
