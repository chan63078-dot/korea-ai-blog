# 금지 표현 목록

## 절대 사용 금지
- "AI가 작성한", "ChatGPT", "클로드", "언어모델" 등 AI 언급
- "~인 것 같습니다", "~일 수도 있습니다" (불확실 표현 남용)
- "매우", "정말", "굉장히", "엄청" (빈도 남용 시 삭제)
- "~하도록 하겠습니다" → "~합니다"로 대체
- "여부", "관련하여", "측면에서" 등 관공서 문투

## AI 티 나는 표현 금지
- "첫째, 둘째, 셋째" 나열형 과용
- "~에 대해 알아보겠습니다" 패턴 반복
- 모든 단락을 같은 길이로 맞추는 패턴
- 결론에서 "이상으로 OOO에 대해 알아봤습니다" 사용

## 사실 관계 주의
- 확인되지 않은 통계·수치 사용 금지
- "최근 연구에 따르면" + 출처 없는 주장 금지
- 특정 인물·기업 부정적 단정 금지

## 대체 표현
| 금지 | 대체 |
|------|------|
| ~하도록 하겠습니다 | ~합니다 |
| ~인 것 같습니다 | ~입니다 / ~으로 보입니다 |
| 매우 중요합니다 | 핵심입니다 |
| ~에 대해 살펴보겠습니다 | (소제목으로 대체) |
