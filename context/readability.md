# 가독성 규칙

## 문장 구조
- 수동태 지양 → 능동태 사용
- 이중 부정 금지 ("~하지 않을 수 없다" → "반드시 해야 한다")
- 한자어·영어 남용 금지 → 쉬운 우리말 우선

## 소제목 활용
- H2: 대주제 구분 (3~5개)
- H3: 세부 항목 (H2 아래 2~3개)
- 소제목만 읽어도 글 전체 흐름이 파악되어야 함

## 목록 활용
- 3개 이상 나열 시 불릿 목록 사용
- 순서가 중요한 경우 번호 목록
- 각 항목 15자 이내 권장

## 강조
- 핵심 키워드 **굵게** (문단당 1~2개 이내)
- 인용·중요 정보는 인용 블록 (`>`) 사용

## 분량
- 최소 800자, 최대 2000자
- 소제목 포함 전체 기준
