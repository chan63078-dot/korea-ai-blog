혹시 SQL 자격증을 따려고 벼르고 있었다면, 이번 주가 중요합니다. SQLD 63회 원서접수가 10월 16일 마감되거든요. 11월 14일 시험을 목표로 한다면 지금 접수부터 끝내야 합니다.

## 63회 시험, 일정부터 확인하세요

SQLD 63회는 시험일 11월 14일, 원서접수는 10월 12일부터 16일까지입니다. 합격자 발표는 12월 4일로 예정되어 있습니다.

접수는 한국데이터산업진흥원 데이터자격검정 홈페이지에서 진행합니다. 응시료는 5만원이고, 올해는 60회부터 63회까지 총 네 번 시행됩니다. 이번 63회를 놓치면 다음 기회는 내년 상반기로 넘어가니, 올해 안에 자격증을 따고 싶다면 이번 주 안에 접수를 마치는 게 안전합니다.

## SQLD는 어떤 시험일까요

SQLD는 SQL 개발자 자격증으로, 데이터모델링과 SQL 활용 두 과목으로 구성됩니다. 객관식 50문항을 90분 안에 풀어야 하고, 과목별 40점 이상·전체 60점 이상이면 합격입니다.

데이터모델링 과목은 엔터티·관계·정규화 같은 설계 이론을 다룹니다. SQL 활용 과목은 실제 질의문을 읽고 결과를 예측하는 문제가 많아서, 이론만 외우기보다 쿼리를 직접 짜보는 연습이 효과적입니다.

## 접수 전 체크리스트

접수를 누르기 전에 아래 세 가지는 미리 확인해두세요.

- 응시지역과 고사장이 원하는 곳으로 남아있는지
- 신분증·사진 등 접수에 필요한 서류를 준비했는지
- 결제수단과 환불 규정(기간별 환불액이 다름)을 확인했는지

접수 인원이 몰리면 희망 지역 고사장이 먼저 마감되는 경우가 많습니다. 오늘 안에 접수를 끝내는 쪽이 유리합니다.

## 합격 전략, 이렇게 준비하세요

접수를 마쳤다면 이제 11월 14일까지 한 달 남은 시간을 어떻게 쓸지가 중요합니다. 데이터모델링은 기출문제로 개념을 반복 확인하는 쪽이 효율적입니다. 정의를 외우는 것보다 기출에서 반복되는 함정 문장 패턴을 파악하는 게 점수에 더 도움이 됩니다.

SQL 활용 과목은 실습 환경에서 직접 쿼리를 입력해보는 연습이 중요합니다. JOIN과 서브쿼리, 윈도우 함수가 매 회차 꾸준히 출제되는 영역이니 이 세 가지는 꼭 손으로 풀어보고 넘어가세요. 모의고사를 2~3회 풀어보면 실제 시험에서 시간 배분을 어떻게 할지 감이 잡힙니다.

데이터 직무나 백엔드 개발 공고에서는 SQL 활용 능력을 거의 기본 조건으로 요구합니다. SQLD는 그 능력을 서류상으로 보여줄 수 있는 가장 접근하기 쉬운 자격증이라, 접수 마감을 넘기지 않는 게 중요합니다.

SQLD는 다른 국가자격증보다 진입장벽이 낮아서 독학 응시자가 많습니다. 시중 교재 한 권과 최근 3~4회분 기출문제만으로도 충분히 준비할 수 있습니다.

실습 환경이 따로 없다면 오라클이 무료로 제공하는 라이브SQL 같은 웹 기반 실습 도구를 활용해보세요. 설치 없이 바로 쿼리를 입력해볼 수 있어서, 이론만 읽고 넘어가는 것보다 훨씬 오래 기억에 남습니다.

한 달 일정으로 짠다면 이런 순서가 무난합니다.

- 1주차: 데이터모델링 핵심 개념 정리
- 2주차: SQL 기본 문법 실습
- 3주차: 기출문제 2~3회분 풀이
- 4주차: 오답 정리와 실전 모의고사

접수를 놓치면 올해 일정은 끝나기 때문에 다음 기회는 해를 넘겨야 합니다. 11월 시험까지 한 달, 짧다고 느껴질 수 있지만 매일 조금씩 쿼리를 짜보는 습관만 들이면 충분히 따라잡을 수 있는 분량입니다.

## 자주 묻는 질문

**비전공자도 합격할 수 있나요?** 네. SQLD는 전공이나 경력 제한이 없는 자격증이라 비전공자 응시자도 많습니다. 데이터모델링 개념이 낯설게 느껴질 수는 있지만, 기출문제 안에서 반복되는 용어 위주로 정리하면 충분히 따라갈 수 있는 난이도입니다.

**이번에 떨어지면 언제 다시 볼 수 있나요?** 올해는 63회가 마지막 회차라서, 이번에 접수를 놓치거나 불합격하면 다음 기회는 해를 넘겨야 열립니다. 그만큼 이번 접수 기간을 놓치지 않는 게 중요합니다.

**ADsP나 빅데이터분석기사와 같이 준비해도 되나요?** 가능합니다. SQLD는 SQL 활용 능력에 집중된 자격증이라, 통계·분석 중심인 다른 데이터 자격증과 과목이 크게 겹치지 않습니다. 목표 직무에 SQL 활용이 필요하다면 먼저 SQLD로 기초를 다지는 순서를 추천합니다.

접수 마감까지 남은 시간이 많지 않습니다. 11월 시험을 노린다면 오늘 안에 접수부터 끝내고, 데이터모델링과 SQL 활용 두 과목을 균형 있게 준비해보세요.
